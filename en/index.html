Personal project

FermeGPU

A dashboard to track and book GPU, CPU and memory resources, with an administrator role and a user role. The backend is a simulator, not connected to real clusters.

See the code on GitHub →

Screenshots

Problem

Track GPUs and models, book resources and allocate them automatically.

Technical choices

  • Angular for the dashboard.
  • Two roles, administrator and user, to separate management from booking.
  • Offline gateways are flagged and can be restarted from the interface.

Diagram

User→ Angular dashboard→ GPU clusters

Features

  • Overview: GPU, memory and CPU load gauges for all connected clusters.
  • Node list: online or offline status, owner, number of physical and virtual GPUs.
  • Bookings: form (application, namespace, model, GPU, CPU, RAM), activation, moving to another node, deletion after confirmation.
  • Network gateways: list, alert for offline gateways, restart button.

What I learned

This project was my first steps in Python, a language I had never used.

What I would do differently

A more minimal version, so it can fit into a startup. It started as a proof of concept for large groups, which can afford solutions that already exist.

Technologies

  • Angular
  • TypeScript

Fortune's Weave Companion

A companion app for the game Fire Emblem: Fortune's Weave, born from the notebook I keep during my playthrough.

Problem

Have a personal companion at hand, without searching the internet each time. The project turns my game notes into a structured tool.

Technical choices

  • FastAPI: game data (units, classes, weapons).
  • Django: players, accounts, administration and the playthrough notebook.
  • Angular front end, once both services are stable.

Diagram

Game notebook→ FastAPI API→ Angular front end (planned)

What I learned

I am currently learning Django, a Python framework I am discovering through this project.

What I would do differently

Start directly with the final stack, to avoid redoing the work once the technical choices are settled.

Technologies

  • FastAPI
  • Python
  • Django
  • Angular
